Registry workflow

  1. Create or select a namespace.
  2. Upload a ZIP containing SKILL.md at its root.
  3. Review the scan result, then approve the version.
  4. Assign the smallest required role to each member or CLI token.

Administrators can manage users, grants, account security, and audit history from the navigation menu.
